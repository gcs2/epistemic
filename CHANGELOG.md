# Changelog

## 0.7.0 — executable investigation development

- Added the Action 0.2 implementation audit and clarified expected-score sensitivity versus outcome risk.
- Added investigation-0.1 schema, reference engine, observation replay, CLI, example and analytic/behavioral tests.
- Compared six policies in two frozen public development runs; retained the first run's full-menu design limitation and the exploratory budget-two extension.
- Kept one-step value-of-information as default: extra lookahead has no established advantage and does not repair misleading likelihoods or absent hypotheses.
- Added outcome-level stakeholder constraints, exact discrete tails, source-family reuse restrictions and complete decision/update traces.
- Preserved nine historical manifested result files as exact Git bytes after discovering line-ending normalization broke clean-checkout integrity.
- Updated canonical research status, interpretation, maintenance instructions and handoff.

These are exposed development results, not independent confirmation or a new general discovery algorithm.

## 0.6.0 — bounded decision assurance foundation

- Added an eight-wave deep-research report, query plan, search log, and claim-to-source ledger.
- Added Action Protocol 0.2 as a separate schema and executable reference engine with typed consequence and value uncertainty.
- Separated evidence quality from consequence arithmetic and added invariance tests preventing signed-confidence shrinkage from returning through that path.
- Added bounded statuses, challenge coverage, assurance deficits, stakeholder constraints, lower-tail outcomes, rank acceptability, regret, and adaptive-learning commitments.
- Preserved Action Protocol 0.1 as a legacy reproduction path and documented manual migration rather than inventing a confidence-to-range conversion.
- Identified recursive benchmark overfitting as a system-level threat and added a protected-confirmation requirement.
- Added a comparative Experiment 003B design draft with strong baselines, component ablations, active stakeholder conflict, learning actions, and decisive falsifiers.
- Added repository maintenance rules, contribution guidance, agent instructions, architecture decision records, and a pull-request checklist.
- Completed a clean, byte-identical Experiment 003A replication and added its final result manifest.

Action 0.2 is executable and behaviorally tested, but it is not yet validated as a superior decision method.

## 0.5.0 — decision stress benchmark

- Added hash-frozen Experiment 003A with 96,000 synthetic cases across 96 factorial cells.
- Retained three unsupported hypotheses, including failures of the robustness gate, minimax regret, and the registered distributional test.
- Documented and corrected a post-run H5 result-classification bug.
- Demonstrated the signed-confidence hazard and disabled action-0.1 robust certification when uncertain negative impacts are present.
- Added five bounded truth gems and advanced the next design target to action protocol 0.2 and Experiment 003B.

This release stress-tests decision mechanics; it does not establish real-world decision benefit.
