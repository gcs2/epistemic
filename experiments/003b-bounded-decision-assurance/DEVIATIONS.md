# 003B development deviations

## D1: Full-menu budget cannot identify ordering effects

The initial frozen run completed with 120 cases per regime and budget three.
Fixed, random and entropy policies used the same full set of three observations,
and consequently had equal terminal outcomes and costs. This is expected Bayesian
order invariance, but a limitation of the design for comparing investigation
selection. No original output, protocol, configuration or engine was altered.

Added BUDGET2_EXTENSION.md, a separate configuration, freeze and output directory.
The follow-up is exploratory development on exposed cases, not confirmation.
