# Architecture Decision Records

Decision records explain durable choices that would otherwise be repeatedly debated or silently reversed.

## Status vocabulary

- **Proposed:** open for implementation or evidence.
- **Accepted:** current project policy.
- **Superseded:** retained for history; another record governs.
- **Rejected:** considered and not adopted.
